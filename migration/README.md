# Migration notes

Each note is named after the version it migrates from: `v0.1.md` explains
workflow dirs and task artifacts written for v0.1. Read only the notes for
the versions you find. A note explains how to read the earlier layout or
forms; the current protocol and templates define what to write.

- Migrate only after the user agrees; never migrate automatically.
- Migrate a workflow dir or task as a whole, from its version to the
  current one, applying each later note in order.
- Keep the meaning of every artifact: IDs, statuses, and history stay as
  they were unless a note says otherwise.
