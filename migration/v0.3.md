# Reading v0.3 task artifacts

Task artifacts written for v0.3 may use forms that the current protocol no
longer describes. Read them as follows; the current protocol and templates
define the forms to write.

## Goal task name

A goal had no `Task name` metadata. Migrating adds `- Task name: <name>`
to the goal's metadata, such as the task dir name; this metadata edit
preserves the goal's meaning and needs no amendment cycle.
