# Reading v0.1 workflow dirs

A workflow dir written for v0.1 has no library. Read it as follows; the
current protocol defines the layout to write.

```text
.waif/
├── .git/                    # Optional workflow repository
├── .gitignore               # Usually ignores /tasks/current
├── charter.md               # Optional project rules
└── tasks/
    ├── YYYYMMDD-N-task-name/
    │   ├── goal.md
    │   ├── plan.md
    │   └── steps/...
    └── current -> ./YYYYMMDD-N-task-name
```

- `charter.md` and `tasks/` are the library's charter and task collection.
  Each task dir has the same internal structure as today.
- `tasks/current` is the current-task pointer, kept inside the task
  collection; when it is absent, no task is selected.
- `.git/` is the workflow repository and holds the library's history.
- `.gitignore` ignores the old pointer path, `/tasks/current`, and the old
  pointer itself may be tracked in the repository's index; the current
  layout ignores `/current_task` and versions `library/`.
- There was no separate library and no instance-local selection outside
  the task collection.
